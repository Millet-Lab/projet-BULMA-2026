# projet-BULMA-2026
Application C# wpf - Application C# web
Projet d'Analyse et de Conception - Bachelier en Informatique, développement d'applications
IPEFA Sup Seraing - Bloc 4

## Description
Application de gestion développée en C# / WPF et Web Forms avec une base de données SQL (PostgreSQL).
Projet académique réalisé de septembre à novembre 2026, avec analyse, conception et développement 
complet suivant le processus unifié.

## Arborescence
- **Bulma.WPF** : Application desktop C# / WPF - interface principale de l'administrateur de Bulma
- **Bulma.Web** : Application web - version navigateur pour les visiteurs et clients de Bulma
- **Database** : Scripts SQL - création et données de la base

## Stack technique
- C# / .NET, WPF, Visual Studio
- Web : HTML, CSS, JavaScript
- Base de données : SQL
- Outils : Git / GitHub

## Fonctionnalités principales
- Gestion des données via interface WPF
- Consultation via interface Web
- Base de données centralisée
- Gestion des produits
- Gestion des commandes
- Gestion des clients
- gestion des authentifications

## Comment lancer le projet
1. Cloner le repo : `git clone https://github.com/Millet-Lab/projet-BULMA-2026.git`
2. Ouvrir `Bulma.WPF` dans Visual Studio
3. Exécuter les scripts dans le dossier `Database`
4. Lancer le projet
